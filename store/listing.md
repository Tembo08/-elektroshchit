Черновик для загрузки в консоль RuStore. Скриншоты — в `store/screenshots/`.

## Полное описание (до 4000 символов)

```
Электрощит — калькулятор квартирного и домового щита для электриков и тех,
кто собирает щит своими руками.

ПРИЛОЖЕНИЕ НЕ ПРОСТО СЧИТАЕТ РОЗЕТКИ. Оно отвечает на вопрос «что купить и
как собрать»: раскладывает нагрузку по линиям, подбирает автоматы, УЗО и
кабель, проверяет падение напряжения и выдаёт спецификацию.

ЧТО УМЕЕТ
• Линии из комнат: розетки (до 10 точек и 3.5 кВт на линию), освещение (до
  15 точек), мощные приборы — каждый на своей линии.
• Коэффициенты спроса: розетки 0.7, свет 1.0, силовые 1.0. Видно и
  установленную, и расчётную мощность — чтобы не покупать лишнего и не
  получить ложное «всё в порядке».
• Автоматы и кабель: сечение растёт, пока не выдержит и нагрев, и норму по
  падению напряжения.
• Падение напряжения по длине трассы: 1 фаза и 3 фазы, норма 5 %.
• УЗО: 30 мА на розетки и свет, 10 мА на санузел, противопожарное 100 мА на
  вводе, ограничение числа линий на одно УЗО, диф-автоматы для отдельных
  приборов.
• Три фазы: распределение линий по наименьшей загрузке, баланс фаз,
  предупреждение о перекосе.
• Заземление TN-C-S, TN-S и TT: для TT проверяется, что каждая линия под УЗО.
• Проверки с уровнями: ошибки, предупреждения, справка. Если есть ошибка —
  PDF помечается «не для монтажа».

ДОКУМЕНТЫ
• Спецификация: автоматы, УЗО, кабель с метражом (+10 % на разделку),
  DIN-модули, рекомендуемый корпус.
• PDF на A4: сводка, однолинейная схема по фазам, проверки, таблица линий,
  спецификация. Сохраняется в «Загрузки» или отправляется через «Поделиться».

ПРОЕКТЫ
• Сохранение объектов, список, открытие, дублирование, удаление.
• Повреждённые данные не теряются: копия сохраняется отдельно.

ЧЕСТНО О ГРАНИЦАХ
• Результат — черновик. Он не заменяет проект, подписанный электриком с
  допуском.
• Нет расчёта селективности по время-токовым характеристикам и проверки
  петли «фаза-ноль»: для этого нужны параметры сети на объекте.
• Нормы ориентированы на жильё (ПУЭ, СП 256.1325800); промышленные объекты
  не покрыты.

КОНФИДЕНЦИАЛЬНОСТЬ
Приложение не собирает персональные данные и не отправляет их в интернет.
Всё, что вы вводите, хранится только на устройстве.
```

## Что приложить в консоли

| Поле | Файл |
|---|---|
| Иконка 512×512 | `store/icon-512.png` |
| Скриншоты (7) | `store/screenshots/01…07*.png` |
| Политика конфиденциальности | `PRIVACY.md` (загрузить как страницу/файл) |
| APK | `dist/elektroshchit-1.0.2-arm64.apk` (и `-arm32` для старых) |
| AAB | `dist/elektroshchit-1.0.2.aab` |

## Примечание по скриншотам

Кадры собраны из настоящих экранов приложения (`test/store_shots_test.dart` →
`store/screenshots/`), с подписями сверху. Перегенерировать:

```bash
flutter test test/store_shots_test.dart --update-goldens
python3 tool/build_store_shots.py
```

Данные демонстрационные: «Квартира, Ленина 5», 62 м², ТУ 15 кВт.
