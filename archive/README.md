# Архив: отрисовка плана

Роман решил: **приложение «Электрощит» делаем без отрисовки помещения.**

Здесь лежат экраны плана, которые были удалены из приложения:
- `plan_ui/plan_editor_screen.dart` — ручной редактор комнат;
- `plan_ui/plan_sheet_screen.dart` — монтажный лист с легендой;
- `plan_ui/svg_import_screen.dart` — импорт SVG из Corel/Inkscape.

Библиотека геометрии осталась в `lib/plan/` (модели, раскладка squarify,
стены, импорт SVG) — она не подключена к UI и ни на что не влияет.
Описание состояния — `lib/plan/README.md`.

Если отрисовка когда-нибудь понадобится, экраны можно вернуть: они
работают с `lib/plan/` и `FloorPlan` из черновика проекта.
