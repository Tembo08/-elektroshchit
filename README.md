# Электрощит

Приложение для расчёта квартирного и домового электрощита. Отвечает на вопрос
«что купить и как собрать», а не «сколько розеток в комнате»: считает линии,
автоматы, УЗО, кабель, падение напряжения и выдаёт спецификацию с PDF-отчётом.

Черновик проекта: результат требует проверки квалифицированным электриком —
приложение честно пишет это в отчёте и подсвечивает ошибки.

## Что умеет

**Расчёт**
- Группировка потребителей в линии с лимитами (розетки — до 10 точек и 3.5 кВт,
  освещение — до 15 точек) и разбиением по комнатам.
- Коэффициенты спроса: розетки 0.7, освещение 1.0, силовые приборы 1.0 —
  сводка показывает и установленную, и расчётную мощность.
- Подбор автомата по току и сечению кабеля; сечение автоматически растёт, если
  не проходит по нагреву или по падению напряжения.
- Падение напряжения по длине трассы: 1 фаза `2·I·L·ρ/S`, 3 фазы `√3·I·L·ρ/S`,
  ρ = 0.0225 (медь при нагреве). Норма — 5 %, настраивается в YAML.
- УЗО: 30 мА на розетки и освещение, 10 мА на санузел, противопожарное 100 мА
  на вводе, ограничение числа линий на одно УЗО, диф-автоматы для отдельных
  приборов.
- Три фазы: распределение однофазных линий по наименьшей загрузке, баланс фаз
  и предупреждение о перекосе, отдельный учёт трёхфазных приборов.
- Система заземления TN-C-S / TN-S / TT: для TT проверяется, что каждая линия
  под УЗО.

**Проверки**
Правила лежат в `assets/norms/ru_2026/stop_scenarios.yaml` (тексты и уровни),
логика — в калькуляторе. Находки делятся на ошибки, предупреждения и справку;
при наличии ошибок PDF помечается «не для монтажа».

**Документы**
- Спецификация: автоматы, УЗО, кабель с метражом (+10 % на разделку), DIN-модули.
- PDF на A4: сводка, однолинейная схема по фазам, проверки, таблица линий,
  спецификация.

**Проекты**
- Сохранение в локальное хранилище, список объектов, открытие, дублирование,
  удаление.
- Повреждённые данные не теряются: копия сохраняется отдельно.

## Нормы

Все числа вынесены в YAML (`assets/norms/ru_2026/`): сечения и допустимые токи,
ряды автоматов и УЗО, правила группировки, коэффициенты спроса, лимиты,
шаблоны объектов. Тот же набор продублирован в
`packages/electrical_core/lib/src/norms/ru_2026/` для тестов; специальный тест
следит, чтобы копии не разошлись.

## Структура

```
lib/                     приложение (Flutter, Riverpod)
  core/                  черновик проекта, тема, провайдеры
  data/                  сохранение проектов (SharedPreferences + JSON)
  export/                генерация PDF
  presentation/          экраны: главная, объект, комнаты, ввод, обзор, результат
packages/electrical_core чистый Dart: модели, калькулятор, загрузка норм
assets/norms/ru_2026/    нормы (YAML) и правила проверок
tool/generate_icon.py    генератор иконок
test/, packages/electrical_core/test/   тесты
```

Ядро не зависит от Flutter — расчёт можно использовать в консоли или в другом
интерфейсе.

## Сборка

```bash
flutter pub get
flutter test                                   # 29 тестов приложения
cd packages/electrical_core && dart test       # 62 теста ядра

flutter run -d linux                           # десктоп
flutter build apk --debug                      # APK для проверки на телефоне
flutter build appbundle --release              # AAB для RuStore
```

Требуется Flutter 3.47+, JDK 17 и Android SDK. Иконки перегенерируются командой
`python3 tool/generate_icon.py` (нужен Pillow).

## Ограничения

- Расчёт черновой: не заменяет проект, подписанный электриком с допуском.
- Нет расчёта селективности по время-токовым характеристикам и проверки
  петли «фаза-ноль» — для этого нужны параметры сети на объекте.
- Нормы ориентированы на жильё (ПУЭ, СП 256.1325800); промышленные объекты не
  покрыты.

## Лицензия

Код проекта — для личного использования автора. Нормы и справочные данные
приведены как ориентир, а не как официальный документ.
