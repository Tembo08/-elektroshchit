# Архив вариантов оформления

Здесь лежат эскизы, которые не вошли в приложение. Код рабочий, но ниоткуда
не импортируется — чтобы вернуть вариант, достаточно импортировать файл.

- `home_hero_variants.dart` — три эмблемы для главного экрана:
  «модули» (DIN-рейки), «однолинейка» (ввод → шина → отводы) и «типографика».
- `panel_illustration.dart` — первый подробный рисунок щита (плоский,
  без анимации). Его заменил `../panel_styles.dart`.

Актуальные стили: `lib/presentation/home/panel_styles.dart`
(`PanelStyle.neon` — выбран для главного экрана).
