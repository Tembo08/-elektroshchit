# Модуль плана помещения (не подключён к приложению)

Роман решил вынести отрисовку плана в **отдельный проект**, а потом
соединить его со щитком. Код оставлен как задел — в приложении он
не используется (точка входа из экрана результата удалена).

## Что здесь есть

- `plan_models.dart` — комнаты, точки, стены, проёмы, JSON.
- `plan_layout.dart` — автоматическая планировка (squarified treemap
  из пакета `treemap`) и расстановка проёмов.
- `plan_walls.dart` — стены с толщиной, двери и окна как проёмы.
- `plan_canvas.dart` — CustomPainter: стены, проёмы, УГО по ГОСТ 21.614.
- `plan_geometry.dart`, `plan_auto.dart`, `plan_seed.dart` — геометрия
  маршрутов, авторасстановка точек, перенос из черновика.

## Что уже проверено

- Раскладка без пересечений, площади сходятся.
- Стены соседних комнат склеиваются в одну, проёмы вырезаются.
- Символ розетки — по ГОСТ 21.614 (полукруг, два контакта, защитный
  контакт вниз).

## Что не сделано

- Топология дверей (кухня выходила проходной через спальню).
- Провода/трассы отключены — рисовались отдельным слоем.
- Нет ручного редактирования стен мышью.

При переносе в отдельный проект: `lib/plan/` + `lib/presentation/plan/`
+ `test/plan_*.dart` переносятся целиком, зависимости — `treemap`,
`electrical_core` (типы комнат), Flutter.
